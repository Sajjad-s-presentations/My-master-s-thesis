# نسخهٔ LaTeX پایان‌نامه

موتور ساخت: **XeLaTeX**؛ بستهٔ فارسی: **XePersian**؛ قلم متن فارسی: **B Zar** با نسخهٔ ضخیم واقعی؛ قلم لاتین: **Latin Modern Roman**. قالب از PDF موجود در همین مخزن بازسازی می‌شود؛ فایل قالب رسمی دیگری ارائه نشده است.

```bash
# Debian / Ubuntu (در محیطی با دسترسی نصب بسته)
apt-get install latexmk texlive-xetex texlive-lang-arabic texlive-latex-extra fonts-dejavu
bash build.sh
```

خروجی نهایی `thesis.pdf` است. فایل‌های موقت در `build/` ساخته می‌شوند و در Git قرار نمی‌گیرند. در محیط ابری فعلی، بستهٔ فارسی از بستهٔ امضاشدهٔ Debian در `/workspace/.texlive` نصب شده و `build.sh` آن را شناسایی می‌کند.

قلم‌های اصلی در `fonts/` قرار دارند و به نصب سراسری قلم وابسته نیستند. برای اعداد متن از B Zar و برای فرمول‌ها از اعداد لاتین استفاده می‌شود؛ جهت فرمول‌ها چپ‌به‌راست است. برای اضافهٔ پس از «ه» از نویسهٔ ترکیبی «ۀ» استفاده می‌شود که قلم اصلی پشتیبانی می‌کند.

شماره‌گذاری بخش‌ها، صفحه‌ها، فرمول‌ها، جدول‌ها، شکل‌ها و فهرست‌ها باید به‌صورت خودکار توسط LaTeX انجام شود. تصویر صفحه‌های پایان‌نامه جایگزین متن قابل‌ویرایش نمی‌شود.
